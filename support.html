fault

Pro is locked after I paid

Preferences, then Restore purchases, on the iPhone signed in with the buying Apple ID. Still stuck? Send the purchase date.

fault

My CSV import shows zero trades

Pick the broker-style file that matches yours; each layout expects its own columns. Files with only a summary, or exported as PDF, cannot be read. Send us the header row (no figures needed) and we will look.

fault

Trades are duplicated after importing twice

Delete the extra entries one by one with Delete trade, or start over with Preferences → Data → Delete all data and import once more.

fault

R-multiple looks off

R is measured against the stop you logged. With no stop, Tradlo uses the default risk per trade from Preferences, so set it first.

fault

How do I back up my journal?

Preferences → Data → Export all trades (CSV) and keep the file. Tradlo itself has no cloud copy, so a device backup or the CSV is your safety net.

fault

I want everything gone

Delete all data, then Delete in the confirm sheet. Delete the app afterwards if you like. To clear the anonymous subscription profile, mail us.

fault

Switching off the free trial

iOS Settings, your name, Subscriptions, Tradlo. Do it a day or more before the trial ends.

fault

Does it link to my broker?

No. Entry is manual or by file import only.
